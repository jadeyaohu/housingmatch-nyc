RUN B — Affordable re-rentals
Schedule: every Monday and Wednesday.

You are collecting public NYC affordable re-rental listings (individual vacant affordable apartments, usually first come, first served) for HousingMatch NYC. Use the attached muse-template.csv as the exact format.

WHAT TO COLLECT
Visit each source below. Copy every affordable re-rental that is currently available. Skip listings marked rented, filled, or closed.
For each source, source_name must be exactly the name in quotes:
  "HDC" https://www.nychdc.com/find-re-rentals
  "Pronto Housing" https://www.prontohousingrentals.com/
  "TF Cornerstone" https://tfc.com/about/affordable-re-rentals
  "MNS" https://www.mns.com/affordable_units
  "Housing Partnership" https://housingpartnership.com/what-we-do/current-vacancies/
  "MHANY" https://www.mutualhousingny.org/affordable-re-rental-units
  "iAfford" https://iaffordny.com/re-rentals
- Open every listing fully: expand any "+N more offerings", "show more" or similar so you see every unit.
- HDC: the income table is in each listing's advertisement PDF. Open the PDF and copy its income table. If a PDF won't open, still add the listing with the income columns blank and say so in notes.
- Units that only accept waiting-list applications (e.g. on Pronto Housing): include them with record_type waitlist instead of skipping them.
- Skip homeownership (for-sale) units.
- record_type: rerental (or waitlist, see above)
- lottery_id: blank.
- source_url: the link of the individual listing page. On Pronto Housing, open the building's card and copy the address bar from that page — never the general https://prontohousingrentals.com/listings page. If a site truly has no page per listing, use the source page and write "no per-listing page" in notes.
- application_start_date and application_end_date: blank, unless the listing states a deadline.
- Put each unit size on its own row (unit_type = Studio, 1BR, ...). Do not list sizes in notes.
- max_income_N is ALWAYS the limit for an N-person household: max_income_1 = 1 person, max_income_2 = 2 people, and so on. If a table starts at 2 people, leave max_income_1 blank and put the 2-person limit in max_income_2. Double-check you have not shifted a column.
- monthly_rent may be a single number or a range such as "2470 - 2806".
- If a listing has no income table, still add one row with the listing details and leave the income columns blank.
- If a source has no available re-rentals today, add nothing for it and say so in your report.

RULES
- Only open public pages. Never log in to a housing site, never submit a form or application, never solve a CAPTCHA. If a site asks you to log in or blocks you, skip it.
- Browse at a normal human pace: one page at a time, a few seconds between pages.
- Copy only what the page shows. If a value isn't on the page, leave the cell blank. Never estimate, calculate, or fill in from other listings.
- Copy numbers exactly. You may drop "$" and commas, but never change digits.

OUTPUT
One CSV with exactly the header row of muse-template.csv, in the same column order:
record_type,source_name,source_url,collected_at,lottery_id,name,borough,address,application_start_date,application_end_date,apply_url,restrictions,unit_type,ami_percent,household_size_min,household_size_max,min_income,max_income_1,max_income_2,max_income_3,max_income_4,max_income_5,max_income_6,max_income_7,max_income_8,monthly_rent,units_available,notes
- One row per line of the listing's income table (one per unit size x AMI level). Repeat the listing's details on every row.
- source_url: the full link of the page you read. collected_at: the date and time you read it, e.g. 2026-11-11T14:30:00-05:00
- borough: Manhattan, Brooklyn, Queens, Bronx, or Staten Island.
- Dates: YYYY-MM-DD.
- restrictions: e.g. "senior 62+", "disability", "veteran", or blank.
- unit_type: Studio, 1BR, 2BR, 3BR, or 4BR+.
- ami_percent: the AMI % for that row, e.g. 60. household_size_min / household_size_max: the household-size range for that row.
- max_income_1 ... max_income_8: maximum income for 1-person ... 8-person households, exactly as printed. Leave blank any size not shown.
- min_income, monthly_rent, units_available: as printed for that row.
- notes: short only, e.g. "voucher holders exempt from minimum income", "$75 application fee". Otherwise blank.
- apply_url: leave blank unless the page links to a separate application page.

UPLOAD
Name the file muse-YYYY-MM-DD-HHMM-B.csv (date and time you finished).
Go to https://github.com/jadeyaohu/housingmatch-nyc/upload/main/data/inbox, upload the file, and commit it directly to main with the message "muse run B". Do not change any other file.
The upload starts the "Update listings" workflow automatically. Open the Actions tab and wait for that run to finish.
