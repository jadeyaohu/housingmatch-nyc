# T003 — Housing Connect: data access rules and detail-page contents
priority: medium · created: 2026-11-09

**Goal:** Claude needs to know what Housing Connect allows before building any automated collection, and exactly which fields its public lottery pages show.

1. Open https://housingconnect.nyc.gov/robots.txt and copy its full text into the result.
2. Find and read the Terms of Use that apply to visitors of housingconnect.nyc.gov (look at page footers; also check https://www.nyc.gov/home/terms-of-use.page). Copy, word for word, any sentence about: automated access, robots, scraping, crawling, data mining, copying or reusing content, commercial use. Give the URL of each.
3. Check whether NYC publishes any official API or data feed for Housing Connect lotteries besides NYC Open Data datasets `vy5i-a666` and `nibs-na6y`. List what you find with links.
4. Open these 3 public lottery pages: https://housingconnect.nyc.gov/PublicWeb/details/7662 , .../7667 , .../7730 . For each, list every section and field shown (for example: rent, units, AMI, household size, income min–max, asset limit, amenities, preferences with percentages, accessibility units, deadlines, how to apply, photos, map). Note which ones appear on all 3 pages.

Do not log in. Do not open "Apply".
